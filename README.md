# MD Service Portfolio

Application web React + Vite en JavaScript pour présenter les services, compétences et projets démo de la micro-entreprise MD Service.

## Lancer le projet

```bash
npm install
npm run dev
```

## Build de production

```bash
npm run build
```

Le projet est prêt pour un déploiement Vercel avec les paramètres Vite par défaut.
